# Enhanced Buyer-Seller Chat Design & Architecture

This module provides the upgraded, modern real-time **Buyer-Seller Chat System** for the Campus Marketplace.

---

## 🎨 Design & UI/UX Improvements

### 1. `ChatPage.tsx` (1-on-1 Chat Thread UI)
- **Pinned Product Context Card**:
  - Displays product tag, title, and "Campus Meetup" status pill pinned under the header so both parties always see what item they are negotiating about.
- **Campus Safety Notice**:
  - Helpful campus safety badge advising safe public meetup spots (Student Union, Campus Library).
- **Date Separators**:
  - Message feed is grouped and partitioned by days (`"Today"`, `"Yesterday"`, or formatted calendar date).
- **Modern Message Bubbles**:
  - **Mine (Sender)**: Dark slate card with white typography, timestamp, and double delivery checkmarks (`✓✓`).
  - **Theirs (Receiver)**: Clean white card with crisp border, timestamp, and contact avatar.
- **Quick Suggestion Carousel**:
  - Scrollable quick prompt chips above the composer:
    - *Buyer Prompts*: `"Is this still available?"`, `"Can we meet at the Campus Library?"`, `"Would you take 10% less?"`, `"Can I pick this up today?"`.
    - *Seller Prompts*: `"Yes, it's still available!"`, `"Library meetup works great for me."`, `"I'm free after 3 PM today."`, `"Price is firm, sorry!"`.
  - Toggle button to quickly show/hide suggestion prompts.
- **Modern Pill Composer**:
  - Full-width pill container with active send state (lights up dark when text is entered).

---

### 2. `MessagesPage.tsx` (Inbox & Inquiries List)
- **Live Search & Filter**:
  - Search bar to find conversations by person's name, item title, or message snippet.
  - Category filter tabs: `"All chats"` and `"Unread"`.
- **Card Design**:
  - Dynamic avatar background colors generated by name hash.
  - Active green online status indicator with white border ring.
  - Contact name with role indicator (`Buyer` or `Seller`).
  - Relative time ago formatting (`"Just now"`, `"5m ago"`, `"10:30 AM"`, `"Yesterday"`).
  - Linked item preview tag with price tag icon.
  - Card press micro-interaction and soft shadows.
- **Polished Empty State**:
  - Informative empty inbox card with a primary action button to browse listings or manage products.
